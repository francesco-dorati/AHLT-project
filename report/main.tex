\section{Introduction}
\subsection{Context}
Agriculture monitoring increasingly relies on aerial imagery to assess crop health, vegetation density, and irrigation practices over large areas. In arid and semi-arid regions, a key practical task is to distinguish \textbf{irrigated olive groves} from \textbf{non-irrigated terrain}, since irrigated plots typically present stronger and more homogeneous vegetation responses than the surrounding dry soil.

The dataset provided for this homework consists of three aerial RGB images showing intensive olive cultivation patterns. In these scenes, the irrigated areas are expected to appear greener and denser, while the background is often sandy/arid with a weaker green component.

\subsection{Objective}
The objective of this homework is to build an image-processing segmentation pipeline (restricted to techniques from this week: histogram analysis and thresholding) that produces a \textbf{binary mask} isolating irrigated olive grove areas from the non-irrigated background.

In our approach, we:
\begin{enumerate}
    \item enhance vegetation using the \textbf{Excess Green Index (ExG)} computed from RGB channels,
    \item select a threshold (using \textbf{Otsu} on the ExG distribution) to obtain an initial binary mask,
    \item apply simple \textbf{morphological post-processing} to clean noise and fill small gaps,
    \item evaluate results using a manually created \textbf{Ground Truth} mask and the \textbf{Intersection over Union (IoU)} metric.
\end{enumerate}

\section{Segmentation Pipeline}
\label{sec:pipeline}
\subsection{Vegetation Index: Excess Green (ExG)}
The first step of the pipeline is to highlight vegetation using a simple index derived from RGB values. Since irrigated olive groves contain denser green vegetation than the arid background, we compute the \textbf{Excess Green Index (ExG)} per pixel:

\begin{equation}
\mathrm{ExG} = 2g - r - b
\end{equation}

where $r, g, b$ are the red, green and blue channels, respectively (normalized to the range $[0,1]$). The factor $2g$ emphasizes the green component, while subtracting $r$ and $b$ suppresses bright soil and residues. As a result, vegetation tends to have higher ExG values than the surrounding terrain.

In practice, the input image is loaded in RGB, converted to floating point, and ExG is computed using a direct per-pixel formula. The following snippet is taken from \texttt{segmentation\_step1.py}:

\begin{minted}[fontsize=\small, linenos]{python}
image = Image.open(image_path).convert("RGB")
rgb_uint8 = np.asarray(image)
rgb = rgb_uint8.astype(np.float32) / 255.0

r = rgb[..., 0]
g = rgb[..., 1]
b = rgb[..., 2]

exg = 2.0 * g - r - b
\end{minted}

\subsection{Thresholding (Otsu / Manual)}
To obtain a binary segmentation from the ExG map, we apply a global threshold $T$ and classify pixels as vegetation when:

\begin{equation}
\text{mask}(x,y) = \begin{cases}
1 & \text{if } \mathrm{ExG}(x,y) \geq T \\
0 & \text{otherwise}
\end{cases}
\end{equation}

In this homework we use \textbf{Otsu's method} to automatically select $T$ from the ExG histogram. Otsu selects the threshold that maximizes the \emph{between-class variance} (equivalently, it finds the split that best separates two classes in the 1D distribution).

The following snippet (from \texttt{segmentation\_step1.py}) shows the thresholding step and the creation of the initial binary mask:

\begin{minted}[fontsize=\small, linenos]{python}
threshold = otsu_threshold(exg)
mask = exg >= threshold
\end{minted}

\subsection{Post-processing (Morphology and Cleaning)}
The raw masks obtained by a single global threshold (Figure~\ref{fig:raw-masks}) may contain small isolated pixels, small holes inside tree blobs, and fragmented regions. To improve the visual quality of the segmentation while staying within classical image processing techniques, we apply a lightweight post-processing step:

\begin{itemize}
    \item \textbf{Opening} (erosion followed by dilation) with a small square structuring element to remove small noise.
    \item \textbf{Closing} (dilation followed by erosion) to fill small gaps and connect fragmented vegetation blobs.
    \item \textbf{Small component removal} to discard connected components below a minimum size threshold.
\end{itemize}

In our implementation we use kernel sizes $3\times 3$ for opening and $5\times 5$ for closing, and we remove connected components smaller than 200 pixels. The key operations (from \texttt{segmentation\_step1.py}) are shown below:

\begin{minted}[fontsize=\small, linenos]{python}
opened = binary_open(mask, k=3)
closed = binary_close(opened, k=5)
cleaned = remove_small_components(closed, min_size=200)
\end{minted}

\section{Evaluation and Error Measurement}
\label{sec:evaluation}
\subsection{Intersection over Union (IoU)}
To quantitatively assess segmentation quality, we compare each predicted binary mask against its corresponding Ground Truth (GT) mask using the \textbf{Intersection over Union (IoU)} metric (also called the Jaccard index). For a predicted foreground set $P$ and GT foreground set $G$ (foreground = irrigated vegetation), IoU is defined as:

\begin{equation}
\mathrm{IoU}(P, G) = \frac{|P \cap G|}{|P \cup G|}
\end{equation}

where $|\cdot|$ denotes the number of foreground pixels. IoU ranges from 0 to 1: a value of 1 corresponds to perfect overlap, while 0 indicates no overlap.

In this report, $P$ is the \textbf{final cleaned mask} produced by the pipeline (Section~\ref{sec:pipeline}), and $G$ is the manually created GT mask (Section~2.2). The IoU values are computed per image and summarized in the next subsection.

\section{Implementation}
\subsection{Code Structure}
The implementation is organized as two small Python scripts:

\begin{itemize}

\section{Conclusion}
This homework implemented a classical image-processing pipeline to segment irrigated olive groves from RGB aerial imagery using only techniques from this week (histogram analysis and thresholding).

The proposed approach combines (i) a vegetation-sensitive ExG index, (ii) a global Otsu threshold to obtain an initial binary mask, and (iii) lightweight post-processing (opening/closing and small-component removal) to produce cleaner and more spatially coherent predictions. Qualitatively, the red-overlay visualizations show that the segmented regions follow the regular orchard texture and canopy layout.

Quantitatively, IoU evaluation against manually created GT masks shows a strong dependence on scene conditions and annotation details: the method performs best on the second image, while performance drops on the first and third images where illumination changes, shadows, or background-green responses make global thresholding less reliable.
